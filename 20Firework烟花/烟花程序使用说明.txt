1. 程序简介
═══════════════════════════════════════════════════════════════

这是一个使用 Processing 编写的交互式烟花模拟程序。

主要特点：
- 4 种不同类型的烟花效果
- 多色渐变粒子系统
- 真实的物理模拟（重力、空气阻力）
- 流畅的拖尾效果
- 可选的音效系统

═══════════════════════════════════════════════════════════════
2. 基本使用方法
═══════════════════════════════════════════════════════════════

运行程序：
1. 在 Processing 中打开 .pde 文件
2. 点击运行按钮（或按 Ctrl+R / Cmd+R）
3. 在弹出的窗口中点击鼠标任意位置

操作说明：
- 点击鼠标：在点击位置发射并引爆烟花
- 烟花类型：每次随机选择 4 种效果之一
- 烟花颜色：自动混合多种颜色

3. 如何修改背景颜色
═══════════════════════════════════════════════════════════════

背景颜色需要在两个地方修改（保持一致）：

位置 1：setup() 函数（第 6 行左右）
----------------------------------------
  background(10, 15, 30);

位置 2：draw() 函数（第 11 行左右）
----------------------------------------
  fill(10, 15, 30, 40);

注意：两处的 RGB 值必须相同，第二处多一个透明度参数（通常是 40）


常见背景颜色示例：
----------------------------------------
深蓝夜空（默认）：
  background(10, 15, 30);
  fill(10, 15, 30, 40);

纯黑色：
  background(0, 0, 0);
  fill(0, 0, 0, 40);

深紫色：
  background(20, 10, 40);
  fill(20, 10, 40, 40);

午夜蓝：
  background(15, 20, 45);
  fill(15, 20, 45, 40);

深灰色：
  background(30, 30, 30);
  fill(30, 30, 30, 40);


RGB 颜色格式说明：
----------------------------------------
- color(R, G, B) 或 color(R, G, B, Alpha)
- R (Red - 红色)：0-255
- G (Green - 绿色)：0-255
- B (Blue - 蓝色)：0-255
- Alpha (透明度)：0（透明）到 255（不透明）

4. 如何修改烟花颜色
═══════════════════════════════════════════════════════════════

每种烟花类型都有独立的配色方案，可以分别修改：

类型 1：中心炸开烟花（createCenterBurst 函数）
----------------------------------------
位置：约第 165 行

  color[] gradientColors = {
    color(255, 50, 80),   // 红色
    color(255, 150, 50),  // 橙色
    color(255, 220, 80),  // 金黄色
    color(255, 100, 150)  // 粉橙色
  };


类型 2：满天星烟花（createStarBurst 函数）
----------------------------------------
位置：约第 185 行

  color[] gradientColors = {
    color(80, 200, 255),  // 天蓝色
    color(150, 100, 255), // 紫色
    color(255, 80, 200),  // 粉色
    color(200, 150, 255)  // 淡紫色
  };


类型 3：尾迹烟花（createTrailBurst 函数）
----------------------------------------
位置：约第 215 行

  color[] gradientColors = {
    color(80, 255, 120),  // 绿色
    color(150, 255, 100), // 黄绿色
    color(255, 255, 150), // 浅黄色
    color(200, 255, 100)  // 青绿色
  };


类型 4：二次爆炸烟花（createDoubleBurst 函数）
----------------------------------------
位置：约第 235 行

  color[] gradientColors = {
    color(255, 50, 80),   // 红色
    color(255, 220, 80),  // 金黄色
    color(255, 255, 150), // 浅黄色
    color(255, 150, 100)  // 橙粉色
  };


颜色修改技巧：
----------------------------------------
1. 可以增加或减少颜色数量（建议 3-6 种）
2. 可以让所有类型使用相同的配色
3. 可以使用渐变色（相近的颜色）或对比色
4. 使用在线工具查找 RGB 值：Google 搜索 "color picker"

5. 如何调整烟花效果
═══════════════════════════════════════════════════════════════

调整粒子数量
----------------------------------------
在每个 createXXXBurst 函数中修改循环次数：

例如：createCenterBurst 函数
  for (int i = 0; i < 80; i++) {  // ← 修改这个数字
    ...
  }

建议值：
- 小型烟花：30-50
- 中型烟花：50-100（默认）
- 大型烟花：100-200
- 超大烟花：200+（注意：可能会卡顿）


调整火箭速度
----------------------------------------
位置：Rocket 类的构造函数（约第 95 行）

  speed = random(8, 12);  // ← 修改这两个数字

建议值：
- 慢速：random(4, 8)
- 正常：random(8, 12)（默认）
- 快速：random(12, 16)


调整粒子扩散速度
----------------------------------------
在每个 create 函数中修改 speed 参数：

  float speed = random(2, 9);  // ← 修改这两个数字

建议值：
- 紧凑效果：random(1, 5)
- 正常效果：random(2, 9)（默认）
- 爆炸效果：random(5, 15)


调整粒子生命周期
----------------------------------------
位置：Particle 类的构造函数（约第 265 行）

  lifespan = random(180, 300);  // ← 修改这两个数字

说明：数值越大，粒子存在时间越长
建议值：
- 短暂：random(100, 200)
- 正常：random(180, 300)（默认）
- 持久：random(300, 500)


调整重力
----------------------------------------
位置：Particle 类的构造函数（约第 263 行）

  acc = new PVector(0, 0.08);  // ← 修改 0.08 这个数字

建议值：
- 微重力：0.03
- 正常：0.08（默认）
- 强重力：0.15


调整空气阻力
----------------------------------------
位置：Particle 类的 update() 函数（约第 287 行）

  vel.mult(0.985);  // ← 修改 0.985 这个数字

说明：越接近 1，阻力越小，粒子飞得越远
建议值：
- 高阻力：0.95
- 正常：0.985（默认）
- 低阻力：0.995

6. 如何添加声音效果
═══════════════════════════════════════════════════════════════

步骤 1：安装 Minim 库
----------------------------------------
1. 在 Processing 中选择：Sketch → Import Library → Add Library
2. 搜索 "Minim"
3. 点击安装


步骤 2：添加代码
----------------------------------------
在文件开头添加：

  import ddf.minim.*;
  
  Minim minim;
  AudioPlayer launchSound;
  AudioPlayer explodeSound;

在 setup() 函数中添加：

  minim = new Minim(this);
  launchSound = minim.loadFile("launch.mp3");
  explodeSound = minim.loadFile("explode.mp3");

在 mousePressed() 函数末尾添加：

  launchSound.rewind();
  launchSound.play();

在 draw() 函数的火箭爆炸处添加（r.explode() 之后）：

  explodeSound.rewind();
  explodeSound.play();


步骤 3：准备音频文件
----------------------------------------
1. 在你的项目文件夹中创建名为 "data" 的文件夹
2. 将音频文件放入 data 文件夹：
   - launch.mp3（发射音效）
   - explode.mp3（爆炸音效）

文件夹结构：
  你的项目文件夹/
  ├── fireworks.pde
  └── data/
      ├── launch.mp3
      └── explode.mp3


获取免费音效：
----------------------------------------
推荐网站：
- Freesound.org（需要注册）
- Zapsplat.com
- Mixkit.co

搜索关键词：
- 发射音效：rocket launch, whoosh, firework launch
- 爆炸音效：firework explosion, burst, bang

支持的格式：.mp3、.wav、.aiff

7. 如何修改界面文字
═══════════════════════════════════════════════════════════════

文字位置：draw() 函数末尾（约第 55-59 行）
----------------------------------------

默认代码：
  fill(255);
  textSize(14);
  text("点击鼠标：发射彩色烟花", 10, 20);
  text("粒子数: " + particles.size(), 10, 40);


删除文字：
----------------------------------------
注释掉或删除这几行即可：
  // fill(255);
  // textSize(14);
  // text("点击鼠标：发射彩色烟花", 10, 20);
  // text("粒子数: " + particles.size(), 10, 40);


修改文字内容：
----------------------------------------
  text("Click to launch!", 10, 20);
  text("Particles: " + particles.size(), 10, 40);


修改文字位置：
----------------------------------------
第一个数字是 X 坐标（横向），第二个是 Y 坐标（纵向）
  text("点击鼠标：发射彩色烟花", 300, 30);  // 移到中间


修改文字颜色：
----------------------------------------
  fill(255, 200, 100);  // 金黄色
  fill(100, 200, 255);  // 天蓝色
  fill(255, 100, 150);  // 粉色


修改文字大小：
----------------------------------------
  textSize(12);   // 小号字体
  textSize(14);   // 默认
  textSize(20);   // 大号字体

8. 常见问题解答
═══════════════════════════════════════════════════════════════

Q1：程序运行很慢/卡顿怎么办？
----------------------------------------
A：减少粒子数量：
   - 在每个 createXXXBurst 函数中减小循环次数
   - 例如：for (int i = 0; i < 50; i++)  改为  for (int i = 0; i < 30; i++)
   - 或者缩短粒子生命周期：lifespan = random(100, 200);


Q2：烟花效果太小/太大怎么办？
----------------------------------------
A：调整粒子扩散速度：
   - 在 createXXXBurst 函数中修改：
   - 太小：float speed = random(5, 15);
   - 太大：float speed = random(1, 5);


Q3：烟花掉落太快怎么办？
----------------------------------------
A：减小重力值：
   - 在 Particle 构造函数中：
   - acc = new PVector(0, 0.04);  // 从 0.08 改为 0.04


Q4：如何让烟花持续时间更长？
----------------------------------------
A：增加粒子生命周期：
   - 在 Particle 构造函数中：
   - lifespan = random(400, 600);  // 从 180-300 增加


Q5：出现 "语法错误" 怎么办？
----------------------------------------
A：检查以下几点：
   1. 确保所有括号都匹配：{ }、( )、[ ]
   2. 确保每行代码末尾有分号 ;
   3. 删除所有 ### 或其他 Markdown 格式标记
   4. 不要在代码中包含中文标点符号（除了注释）


Q6：声音不播放怎么办？
----------------------------------------
A：检查以下几点：
   1. 确认已安装 Minim 库
   2. 确认 data 文件夹存在且在正确位置
   3. 确认音频文件名完全匹配（包括大小写）
   4. 尝试使用 .wav 格式代替 .mp3
   5. 检查音频文件是否损坏（用其他播放器测试）


Q7：如何改变画布大小？
----------------------------------------
A：在 setup() 函数中修改：
   - size(800, 600);  改为你想要的尺寸
   - 例如：size(1024, 768); 或 size(1920, 1080);


Q8：如何让烟花从不同位置发射？
----------------------------------------
A：在 mousePressed() 函数中修改：
   - 当前：rockets.add(new Rocket(width / 2, height, ...));
   - 随机位置：rockets.add(new Rocket(random(width), height, ...));
   - 从左边：rockets.add(new Rocket(0, height, ...));
   - 从右边：rockets.add(new Rocket(width, height, ...));


Q9：如何保存为可执行文件？
----------------------------------------
A：在 Processing 中：
   1. File → Export Application
   2. 选择目标平台（Windows, Mac, Linux）
   3. 点击 Export
   4. 在 application.xxx 文件夹中找到可执行文件


Q10：如何自动连续发射烟花？
----------------------------------------
A：在 draw() 函数中添加（在更新火箭之前）：
   if (frameCount % 60 == 0) {  // 每 60 帧（1秒）发射一次
     int randomType = int(random(4));
     color[] colors = {...};
     color chosenColor = colors[int(random(colors.length))];
     rockets.add(new Rocket(width/2, height, 
       random(width), random(height/2), randomType, chosenColor));
   }
