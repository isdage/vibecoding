基本信息
--------
- 作品名称：吃西瓜（Watermelon Bite）
- 创作平台：Processing（Java 模式）
- 版本：v1.0（无声版 / No-Sound）
- 创作者：@iSDAGE
- 代码文件：watermelon/sketch_xigua.pde（示例名；你的实际文件名为当前 .pde）

项目简介
--------
《吃西瓜》是一款高性能的 2D 交互插画：
- 果肉/果皮采用弧形渐变，籽为椭圆随机分布；
- 鼠标点击可在西瓜边缘“咬一口”，像素级抠除得到真实牙印；
- 触发“弧线溅射 → 下落 → 触地淡渍”的克制粒子特效；
- 背景径向渐变缓存到离屏图层（bgPG），提升帧率；
- Retina/高分屏使用 pixelDensity(1) 以避免像素翻倍导致的掉帧；
- 全程无声音。

核心交互（Controls）
-------------------
- **Click（点击）**：在可咬区域点击（默认为西瓜的“下半部”）会生成一处**牙印**并触发**弧线溅射粒子**；
- **R（Reset）**：重置场景（清空牙印、溅射、淡渍），重建西瓜层；
- **S（Save）**：保存当前画面为 `watermelon_bite_####.png`；
- **自动节能**：当场景静止（无溅射动画且无需重建）时 `noLoop()` 进入省电模式；有动画或重建请求时自动 `loop()`。

视觉与物理机制
--------------
- **西瓜与籽**：
  - 以 CENTER 为基点（默认在画布中心向上偏移 `OFFSET_Y=-100`）绘制；
  - 果皮（绿）与果肉（红）采用 `arcGradient()` 叠加式弧形渐变；
  - 椭圆籽（`SEED_W/SEED_H`）在果肉区域随机分布，带随机旋转与缩放。

- **牙印（Bite）**：
  - 点击生成一个“主圆”+ 2~3 个随机小瓣（`lobes`），像素级抠除（置 `alpha=0`）以获得真实缺口边缘；
  - 命中判定 `pointInsideWatermelon()`：要求在**外圆内**且**位于西瓜下半部**（考虑旋转后可视半部为可咬区域）。

- **弧线溅射（ArcDrop） & 触地淡渍（Splat）**：
  1) **阶段一（弧线飞行）**：粒子沿以咬点为圆心的小半径圆弧短程飞行；
  2) **阶段二（重力下落）**：结束弧线后按切向初速度进入重力衰减下落（带轻微空气阻力）；
  3) **触地**：在画面底部附近生成扁椭圆形**淡渍**（逐帧淡出直至消失）。
  - 设计克制：每口约 6~12 粒子；颜色为柔和红橙系，保证“干净又有活力”的观感。

性能优化
--------
- **离屏缓存**：
  - `bgPG`：缓存背景径向渐变（一次构建，多次复用）；
  - `fruitPG`：西瓜主图层（果皮/果肉/籽），仅在 `dirty==true` 时重建；
- **像素密度**：`pixelDensity(1)` 避免高分屏像素翻倍引发的负担；
- **按需刷新**：场景静止自动 `noLoop()`，仅在交互/动画时 `loop()`。

安装与运行
----------
方式一：源码运行（推荐）
1. 安装 Processing 4.x（Java 模式）：https://processing.org/download
2. 打开 .pde 源码（本示例默认 `size(800,1100)`，Java2D 渲染器）
3. 点击左上角 ▶️ 运行即可体验交互

方式二：导出应用程序
1. 在 Processing 中打开 .pde
2. 选择 **File > Export Application...**
3. 勾选对应平台（macOS / Windows）并导出 `.app / .exe` 直接运行

系统需求
--------
- 操作系统：macOS / Windows / Linux
- 软件环境：Processing 4.x（Java 模式）
- 渲染：Java2D（默认）；如需 P2D/全屏可自行调整（注意粒子与渐变的表现差异）

可调参数（代码顶部）
-------------------
- **视觉**：
  - `R`（西瓜半径）、`OFFSET_Y`（垂直偏移）
  - `SEED_COLOR`、`SEED_W`、`SEED_H`、`SEED_COUNT`
  - 背景渐变色：`BG_INNER` / `BG_OUTER`
- **粒子**（在 `spawnArcSplash()` / `ArcDrop` 中）：
  - 数量范围、弧半径、弧时长 `dur`、粒子半径 `rad`、重力与阻尼系数
- **淡渍**：`Splat.life`（生存帧数）、初始尺寸等

文件说明
--------
- **sketch_*.pde**：主程序（网格与旋转、渐变、牙印抠除、粒子/淡渍、离屏缓存、交互/存档、节能循环）
- **/data**（可选）：后续若加入外部贴图/字体，可放于此
- **输出**：截图保存为 `watermelon_bite_####.png`

常见问题（FAQ）
--------------
1) **点击没反应？**  
   - 需在可咬区域（西瓜下半部且在圆内）点击；
   - 若窗口大小改动后定位偏差，请重新运行或按 `R` 重置。

2) **帧率波动？**  
   - 确认 `pixelDensity(1)` 已启用；
   - 保持默认 Java2D 渲染；
   - 粒子数量与弧线时长适度保守（已内置克制配置）。

3) **希望更“脆/湿”的视觉？**  
   - 可在 `ArcDrop.render()` 与 `Splat.render()` 中微调颜色与透明度；
   - 也可增加少量高光椭圆或径向模糊以提升质感（注意保持风格节制）。
