
Bubble Wand — v1.0 (Processing/Java) — 使用说明书
================================================

文件定位
--------
此说明书适用于你粘贴在 Processing（Java 模式）的最终代码：
“Dreamy Radial Background + Bottle Base — v1.0 (Hollow Radial Bubbles + Bounce)”

概览
----
一个可交互的吹泡泡场景：
- 背景与玻璃瓶为径向渐变；瓶内有动态水面和上浮小气泡。
- 泡泡棒（圆环+棒身）随鼠标移动。需要先将圆环接触瓶口“蘸膜”，
  然后对着麦克风吹气才会生成泡泡；停止吹气后，膜会被清空。
- 吹出的泡泡中心透明、边缘亮，无描边，缓慢上升、触碰边缘弹回、再逐渐消散。

运行环境
--------
- Processing 4.x（Java 模式）
- 需要启用麦克风权限（用于检测吹气音量）

基本交互
--------
- 鼠标移动：控制泡泡棒位置（圆环在上，棒身在下）。
- 将圆环移到瓶颈位置（瓶口判定区）即可“蘸膜”。
- 对麦克风吹气：超过阈值（BLOW_ON）开始生成泡泡；
  当声音回落到下阈值（BLOW_OFF）以下时，视为“停止吹气”，若本轮使用过膜，将清除膜。
- 按键 `v`：开/关调试信息（显示音量、电平阈值、是否在吹、是否有膜）。

关键变量总表（可调节项）
----------------------
【画布/自适应】
- LOGIC_W / LOGIC_H：逻辑画布尺寸（不随窗口变化）。
- SF：等比缩放系数（自动计算）。

【背景与瓶】
- RINGS：渐变圈数（越大越柔和，性能稍降）。
- BG_CX/BG_CY/BG_R/BG_IN/BG_OUT：背景径向中心/半径/颜色。
- BTL_X/BTL_Y/BTL_W/BTL_H：瓶身位置与尺寸。
- NECK_W/NECK_H：瓶颈尺寸。
- CORNER：瓶子圆角半径（当前为 0）。

【水体】
- WATER_LEVEL：水位（相对瓶高 0..1）。
- WAVE_A/WAVE_LEN/WAVE_SPEED：水面波幅/波长/速度。
- WATER_TOP/WATER_BOT：水体渐变颜色（含 alpha）。
- WATER_ALPHA：整体透明度系数（0~1）。
- WATER_STRIPS：水体纵向渐变条数。

【麦克风与吹气】
- BLOW_ON（0.065）：启动吹气阈值（上阈）。
- BLOW_OFF（0.045）：停止吹气阈值（下阈）。
- level / levelSmooth：麦克风电平与平滑值。
- blowing：当前是否处于“吹气中”。

【泡泡棒（WAND）】
- WAND_CX/WAND_CY：初始位置（随鼠标 lerp 到达）。
- WAND_RING_R：圆环半径（同时影响初始泡泡大小基准）。
- WAND_RING_STROKE：圆环描边粗细（白）。
- WAND_STICK_W/WAND_STICK_H：棒身宽高。
- WAND_STICK_COL：棒身颜色。
- WAND_EASE：跟随平滑度（0.12~0.25 手感较好）。

【膜状态】
- filmAvailable：是否当前有膜（蘸到瓶口即获得）。
- filmConsumed：本轮吹气是否消耗过膜（用于停吹后清除膜）。

【泡泡外观/行为】
- BUBBLE_CENTER / BUBBLE_EDGE：泡泡中心与边缘颜色（含 alpha）。
  - 目前：中心透明（alpha=0），边缘微亮（alpha≈10）。
- RADIAL_RINGS：泡泡径向层数（越大越柔和）。
- BUBBLE_USE_ASPECT：是否启用轻微的呼吸式拉伸（椭圆化）。
- BUBBLE_ASPECT_BREATH / BUBBLE_ASPECT_SPEED：拉伸幅度与速度。

【泡泡运动与寿命】
- BASE_UP_SPEED：基础上升速度（越小停留时间越久）。
- NOISE_DRIFT：噪声侧向漂移强度（越大越分散）。
- GROW_RATE：飞行中缓慢变大系数（接近 1 越慢）。
- MAX_R：半径上限（超过则结束）。
- LINGER_FADE_TOP / LINGER_FADE_BODY：寿命衰减（顶部/中段），数值越小越耐久。
- EDGE_BOUNCE_DAMP：触及边界后的速度保留（0~1，越大越弹性）。
- SEPARATION_RADIUS / SEPARATION_FORCE：泡泡之间的分离半径与力（避免重叠）。

如何调整“泡泡大小”
------------------
1) 初始大小：由圆环半径和构造函数共同决定。  
   - 快调：增大/减小 `WAND_RING_R`。  
   - 精调：在 `new Bubble(...)` 中：
     ```java
     this.r = max(6, baseR * (0.8 + pow * 1.8));
     ```
     - 想更大：提高常数（如 0.9）或系数（如 2.0）
     - 想更小：减小它们。

2) 成长速度：`GROW_RATE`（默认 1.002；越靠近 1 越慢）。

3) 上限：`MAX_R`（默认 180）。

如何调整“泡泡持续时间/停留感”
------------------------------
- 调小 `LINGER_FADE_TOP` / `LINGER_FADE_BODY`（如 0.002 / 0.001）。
- 调小 `BASE_UP_SPEED`（上升慢，停留久）。
- 调高 `EDGE_BOUNCE_DAMP`（触壁时保留更多速度）。
- 需要整体更淡或更亮：调 `BUBBLE_EDGE` 的 alpha，和/或调 `RADIAL_RINGS`。

如何调整“吹气灵敏度”
----------------------
- `BLOW_ON`（上阈）越低越容易触发吹气；`BLOW_OFF`（下阈）越高越容易判定停止。  
- 如果你吹不出来：适当降低 `BLOW_ON`（如 0.055）。  
- 如果太容易误触发：适当提高 `BLOW_ON`（如 0.075）。

生成频率
--------
- 冷却：`COOLDOWN_MIN` / `COOLDOWN_MAX`（数越小越频繁）。
- 每次生成数量：
  ```java
  int n = 1 + (over > 0.55 ? 1 : 0);
  ```
  可拓展为更细的分档：
  ```java
  int n = 1 + (over > 0.35 ? 1 : 0) + (over > 0.75 ? 1 : 0);
  ```

性能建议
--------
- 降低 `RINGS`、`RADIAL_RINGS`、`WATER_STRIPS`。
- 降低画布 LOGIC_W/LOGIC_H 或减少泡泡数量（增大冷却时间）。
- 如需非常丝滑，可将 `frameRate(60)` 调高至 `75`（代价是更高占用）。

常见问题（Troubleshooting）
---------------------------
Q1：吹气没反应？  
A：确保系统麦克风权限已授予 Processing；在相对安静环境下测试，若仍无效，降低 `BLOW_ON`。  
按 `v` 开启调试栏，观察 `smooth` 值是否越过上阈。

Q2：没有“膜”效果/无法生成泡泡？  
A：需要先将圆环移动到瓶颈判定区域（mouth）进行“蘸膜”。一旦吹气结束，本轮膜会被清除。

Q3：泡泡太淡/太亮？  
A：修改 `BUBBLE_EDGE` 的 alpha（最后一个参数），例如：  
`color(255,255,255, 18)` 更亮，`color(255,255,255, 8)` 更淡。

Q4：泡泡穿出边界？  
A：请保留边界检测与回弹段落；或者调高 `EDGE_BOUNCE_DAMP`。
