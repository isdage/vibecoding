========================================
1. 基本信息
========================================

程序名称：gaze_text_decay 凝视后的雨停
开发环境：Processing 3.x 或 4.x
画布尺寸：600 x 800 像素

主要特点：
  - 使用 background.jpg 作为背景图片
  - 使用 经典宋体简.ttf 作为中文字体
  - 开始时画面处在下雨状态
  - 鼠标悬停在普通句子上，该句会保持变灰、变模糊
  - 鼠标悬停在“我很想你”上，会触发主要效果
  - 触发后，雨会慢慢停下
  - 除“我很想你”以外的文字会飞散、模糊、淡出，并在末段轻微放大
  - 部分消散后的文字会变成星星，像流星一样落到底部并反弹
  - 星星落地后不会消失，会保持低频闪烁
  - 最后三行“雨停了 / 天晴了 / 我来找你”会在星星阶段慢慢闪烁出现
  - 按 R 键可以重置画面


========================================
2. 安装与运行
========================================

步骤1：安装 Processing
  - 访问 https://processing.org/download
  - 下载并安装适合你电脑系统的版本

步骤2：打开项目文件夹
  - 找到项目文件夹：gaze_text_decay
  - 打开 gaze_text_decay.pde

步骤3：确认资源文件
  - background.jpg 需要和 gaze_text_decay.pde 放在同一个文件夹里
  - 经典宋体简.ttf 需要和 gaze_text_decay.pde 放在同一个文件夹里
  - 当前程序不需要安装额外库
  - 当前程序不使用声音、麦克风或摄像头

步骤4：运行程序
  - 点击 Processing 左上角的运行按钮
  - 或按快捷键：
    Windows/Linux：Ctrl + R
    Mac：Cmd + R

注意：
  - 如果背景没有显示，优先检查 background.jpg 文件名是否完全一致
  - 如果字体没有显示，优先检查 经典宋体简.ttf 是否和 pde 文件在同一文件夹
  - 如果修改了资源文件名，需要同步修改代码里的 loadImage() 或 createFont()


========================================
3. 交互方式
========================================

普通文字悬停：
  - 鼠标移动到普通句子上时，该句会逐渐变灰、变模糊
  - 鼠标离开后不会恢复，保持被看见后的模糊状态
  - 这个效果用于表现文字被凝视后留下痕迹

触发“我很想你”：
  - 鼠标移动到“我很想你”这一行时，程序会进入消散状态
  - 触发后，雨会逐渐变淡，像天气慢慢放晴
  - 除“我很想你”以外，其他文字会开始四散、模糊、淡出
  - 文字消散末段会轻微放大，形成一点透视感
  - 部分文字彻底消失后会变成黄色四角星
  - 星星会向下坠落，落到底部附近后反弹
  - 星星落地后会停留，并保持很慢的闪烁

结尾文字：
  - “雨停了 / 天晴了 / 我来找你”一开始不会出现
  - 进入星星阶段后，这三行会慢慢浮现
  - 出现时带有类似星星闪烁的明暗变化

重置：
  - 按 R 或 r 可以重置画面
  - 重置后，文字、雨、星星、结尾文字都会回到初始状态


========================================
4. 画面结构说明
========================================

画面由这些部分组成：
  - 背景图片 background.jpg
  - 触发前的雨线和落点涟漪
  - 中间排版的中文段落
  - 核心触发句“我很想你”
  - 消散过程中的文字碎片
  - 由文字转化而来的黄色星星
  - 结尾三行文字

图层顺序：
  1. 背景图片
  2. 雨线和涟漪
  3. 正文文字
  4. 消散文字
  5. 流星和落地星星
  6. 结尾文字

说明：
  - 每一行文字都是一个 SentenceLine 对象
  - “我很想你”这一行是特殊触发对象，不参与自身消散
  - 其他文字在触发后按字符单独飞散
  - 每个字符有自己的飞散方向、延迟、旋转角度和星星概率
  - 雨滴和涟漪使用 RainDrop 与 RainRipple 对象绘制
  - 结尾文字使用 EndingLine 对象单独控制出现和闪烁

----------------------------------------
画布和资源
----------------------------------------

【画布尺寸】
位置：setup()
代码：size(600, 800);
说明：
  - 600 是画布宽度
  - 800 是画布高度

【背景图片】
代码：
  bg = loadImage("background.jpg");
  bg.resize(width, height);
说明：
  - 背景图片文件名必须是 background.jpg
  - 图片需要放在 gaze_text_decay.pde 同一文件夹中
  - 程序会把背景图缩放到画布大小

【文字字体】
代码：
  songti = createFont(sketchPath("经典宋体简.ttf"), textSizeValue, true);
说明：
  - 字体文件名必须和代码中完全一致
  - 字体文件需要放在 gaze_text_decay.pde 同一文件夹中
  - 如果换字体，需要修改 createFont() 里面的文件名

文字排版
----------------------------------------

【文字大小】
代码：float textSizeValue = 13;
说明：
  - 控制正文和结尾文字字号
  - 数值越大，文字越大
  - 数值越小，文字越小

【段内行距】
代码：float lineGap = 22;
说明：
  - 控制同一段内每行文字之间的距离
  - 数值越大，段内行距越松
  - 数值越小，段内行距越紧

【段落间距】
代码：float paragraphGap = 39;
说明：
  - 控制段落和段落之间的距离
  - 数值越大，段落之间空隙越大
  - 数值越小，段落之间更紧凑

【文字横向中心】
代码：float textCenterX = 300;
说明：
  - 控制正文整体的水平中心位置
  - 数值越大，整体越靠右
  - 数值越小，整体越靠左

【文字起始高度】
代码：float topY = 200;
说明：
  - 控制第一段文字的起始高度
  - 数值越大，整体越靠下
  - 数值越小，整体越靠上

【正文内容】
代码：String[][] paragraphs = { ... };
说明：
  - 每一组花括号是一段
  - 每一行引号中的文字是一行
  - “我很想你”这一行目前写作：“我很想你”，带中文引号

========================================
6. 常见问题
========================================

问题1：背景图没有显示
  - 确认 background.jpg 和 gaze_text_decay.pde 在同一个文件夹
  - 确认文件名完全是 background.jpg
  - 如果改了文件名，需要同步修改 loadImage("background.jpg")

问题2：字体没有显示或变成默认字体
  - 确认 经典宋体简.ttf 和 gaze_text_decay.pde 在同一个文件夹
  - 确认 createFont() 中的字体文件名完全一致
  - 如果字体文件被放进 data 文件夹，路径也需要相应调整

问题3：鼠标停在“我很想你”上没有触发
  - 确认文字内容是否仍然是“我很想你”，并且包含中文引号
  - 如果改了这行文字，需要修改 isLoveLine 的判断
  - 检查鼠标是否真正停在文字区域内

问题4：雨太明显或太抢画面
  - 减小 rainAlphaMax
  - 减小 rainCount
  - 减小 rainLengthMax

问题5：雨太少或不明显
  - 增大 rainCount
  - 增大 rainAlphaMax
  - 增大 rainLengthMin 和 rainLengthMax

问题6：触发后雨停得太快或太慢
  - 修改 rainFadeOutSpeed
  - 数值越大，雨停得越快
  - 数值越小，雨停得越慢

问题7：文字消散太快
  - 减小 disperseSpeed
  - 增大 fadeStart
  - 增大 fadeSlowness

问题8：文字散得不够开
  - 增大 scatterXRange
  - 增大 scatterUpRange
  - 增大 scatterDownRange
  - 增大 characterSpread

问题9：星星太少
  - 增大 starChance
  - 例如从 0.30 改成 0.45

问题10：星星太多
  - 减小 starChance
  - 例如从 0.30 改成 0.18

问题11：落地星星太暗
  - 增大 groundedStarAlpha
  - 也可以适当增大 starMaxSize

问题12：结尾三行出现太早或太晚
  - 修改 endingAppearAtDisperse
  - 数值越大，出现越晚
  - 数值越小，出现越早

问题13：运行有卡顿
  - 减小 rainCount
  - 减小 rainRippleCount
  - 减小 starChance
  - 减小 starMaxSize
  - 如果仍然卡顿，可以减少正文文字数量
