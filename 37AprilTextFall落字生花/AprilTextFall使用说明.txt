========================================
1. 基本信息
========================================

程序名称：AprilTextFall 四月天文字花瓣
开发环境：Processing 3.x 或 4.x
画布尺寸：600 x 800 像素

主要特点：
  - 使用 background.jpg 作为背景图片
  - 使用 Songti SC 作为文字字体
  - 画面上方显示《你是人间的四月天》中的四行文字
  - 鼠标碰到文字时，文字会变成 1 到 3 片白色花瓣散开掉落
  - 花瓣会随机落在画面 40% 到 90% 的高度范围内
  - 花瓣停稳后，会从落点长出一朵白色小花
  - 花朵根茎是白色曲线，部分花朵会随机带叶子
  - 按空格键会触发一阵风：背景淡绿色花瓣从右上飘向左下
  - 按空格时，已经长出的花朵会轻微向左摆动
  - 按 R 键可以重置画面


========================================
2. 安装与运行
========================================

步骤1：安装 Processing
  - 访问 https://processing.org/download
  - 下载并安装适合你电脑系统的版本

步骤2：打开项目文件夹
  - 找到项目文件夹：AprilTextFall
  - 打开 AprilTextFall.pde

步骤3：确认资源文件
  - background.jpg 需要和 AprilTextFall.pde 放在同一个文件夹里
  - 当前代码使用系统字体 Songti SC
  - Fangzheng.ttf 可以保留在文件夹中，但当前代码不会使用它
  - 当前程序不需要安装额外库
  - 当前程序不使用声音、麦克风或摄像头

步骤4：运行程序
  - 点击 Processing 左上角的运行按钮
  - 或按快捷键：
    Windows/Linux：Ctrl + R
    Mac：Cmd + R

注意：
  - 如果背景没有显示，优先检查 background.jpg 文件名是否完全一致
  - 如果宋体没有显示，说明你的系统字体名称可能不同，可以把 createFont("Songti SC", fontSize, true) 改成其他字体名称
  - 如果想使用文件夹里的 Fangzheng.ttf，可以把字体代码改回 createFont("Fangzheng.ttf", fontSize, true)


========================================
3. 交互方式
========================================

鼠标触碰文字：
  - 程序运行后，四行文字显示在画面上方
  - 鼠标移动到文字附近时，文字会被触发
  - 被触发的字会消失，并散成 1 到 3 片白色花瓣
  - 花瓣会向外散开，然后慢慢落下
  - 花瓣落到随机高度后停住
  - 花瓣停稳后，会从落点长出一朵花

花朵生长：
  - 花朵从花瓣落点附近抽出
  - 根茎会以曲线方式长出
  - 花头会在根茎末端展开
  - 花瓣数量会在 3 到 8 之间随机变化
  - 7 到 8 片花瓣的花朵会显示中间黄色圆心
  - 少量花朵会随机带叶子

空格吹风：
  - 按空格键、Enter 或 Return 会触发一阵风
  - 背景淡绿色花瓣会从右上飘向左下
  - 已经长出的花朵会顺着风向轻微向左摆动
  - 风力会逐渐衰减，不会一直持续

重置画面：
  - 按 R 键可以重置画面
  - 所有花、花瓣、已消失的文字都会恢复到初始状态


========================================
4. 画面结构说明
========================================

画面由这些部分组成：
  - 背景图片 background.jpg
  - 初始诗句文字
  - 文字散落后形成的白色花瓣
  - 花瓣落点长出的白色花朵
  - 按空格触发的背景淡绿色花瓣

图层顺序：
  1. 背景图片
  2. 背景飘动花瓣
  3. 生长出来的花朵
  4. 文字散落形成的花瓣
  5. 还没有被触发的文字

说明：
  - 每个字都是一个 LetterPiece 对象
  - 每片掉落花瓣都是一个 FallingPetal 对象
  - 每朵花都是一个 Flower 对象
  - 背景飘动花瓣是 WindPetal 对象
  - 鼠标不会直接生成花朵，花朵只会从掉落花瓣停住的位置长出来
  - 空格不会生成前景花朵，只负责触发背景花瓣和花朵摆动


========================================
5. 参数调整指南
========================================

提示：
  - 使用 Ctrl + F 或 Cmd + F 搜索参数名称
  - 修改数值后重新运行程序查看效果
  - 建议每次只改一两个参数，方便判断变化

----------------------------------------
画布和资源
----------------------------------------

【画布尺寸】
位置：setup()
代码：size(600, 800);
说明：
  - 600 是画布宽度
  - 800 是画布高度

【背景图片】
代码：bg = loadImage("background.jpg");
说明：
  - 背景图片文件名必须是 background.jpg
  - 图片需要放在 AprilTextFall.pde 同一文件夹中
  - 程序会把背景图缩放到 600 x 800

【文字字体】
代码：font = createFont("Songti SC", fontSize, true);
说明：
  - 当前字体使用系统字体 Songti SC
  - 如果想换成字体文件，把字体文件放在同一文件夹里，再把字体名称改成对应文件名
  - 例如：createFont("Fangzheng.ttf", fontSize, true)

----------------------------------------
文字排版
----------------------------------------

【文字内容】
代码：
  String[] poem = {
    "你是一树一树的花开，",
    "是燕在梁间呢喃，",
    "你是爱，是暖，是希望，",
    "你是人间的四月天！"
  };
说明：
  - 每一行就是画面中的一行文字
  - 如果要换文字，直接修改引号里的内容

【文字大小】
代码：float fontSize = 14;
说明：
  - 控制诗句字号
  - 数值越大，文字越大
  - 数值越小，文字越小

【行间距】
代码：float lineHeight = 28;
说明：
  - 控制每两行文字之间的垂直距离
  - 数值越大，行距越松
  - 数值越小，行距越紧

【第一行高度】
代码：float startY = 105;
说明：
  - 控制第一行文字的 Y 位置
  - 数值越大，整段文字越靠下
  - 数值越小，整段文字越靠上

【文字水平中心】
代码：float centerX = 300;
说明：
  - 控制文字整体的水平中心
  - 300 是 600 宽画布的正中间
  - 数值越大，文字整体越靠右
  - 数值越小，文字整体越靠左

----------------------------------------
鼠标触发文字
----------------------------------------

【鼠标触发范围】
代码：float triggerRadius = 24;
说明：
  - 控制鼠标距离文字多近时触发掉落
  - 数值越大，鼠标离字更远也会触发
  - 数值越小，需要更靠近字才会触发

【字散成花瓣的数量】
位置：LetterPiece.checkMouse()
代码：int count = int(random(1, 4));
说明：
  - 当前每个字会散成 1 到 3 片花瓣
  - random(1, 4) 在 int() 后会得到 1、2、3
  - 如果想更多，可以改成 random(2, 6)

【花瓣炸开力度】
代码：float petalBurstPower = 2.2;
说明：
  - 控制字变成花瓣时向外散开的力度
  - 数值越大，花瓣散得越开
  - 数值越小，花瓣更贴近原来的字

【花瓣落点高度范围】
代码：
  float petalLandingTop = 1.2 / 3.0;
  float petalLandingBottom = 4.5 / 5.0;
说明：
  - petalLandingTop 控制花瓣最上方可能停住的位置
  - petalLandingBottom 控制花瓣最下方可能停住的位置
  - 当前范围约为画面高度的 40% 到 90%
  - 想让花更靠上，就把 petalLandingTop 调小
  - 想让花更靠下，就把 petalLandingBottom 调大

----------------------------------------
花朵生长
----------------------------------------

【花朵根茎高度】
代码：
  float flowerMinHeight = 22;
  float flowerMaxHeight = 158;
说明：
  - 控制花朵根茎的随机高度范围
  - flowerMinHeight 是最短根茎
  - flowerMaxHeight 是最高根茎

【花朵生长速度】
代码：float flowerGrowSpeed = 0.035;
说明：
  - 控制花从地面抽出、展开的速度
  - 数值越大，花长得越快
  - 数值越小，花长得越慢

【花瓣长度】
代码：float petalSize = 22;
说明：
  - 控制花朵单片花瓣的长度
  - 数值越大，花瓣越长
  - 数值越小，花瓣越短

【花瓣数量】
代码：
  int flowerPetalMin = 3;
  int flowerPetalMax = 8;
说明：
  - 控制每朵花的花瓣数量随机范围
  - 当前每朵花会有 3 到 8 片花瓣
  - 7 到 8 片花瓣的花会显示黄色圆心

【花朵整体大小】
代码：
  float flowerMinScale = 0.58;
  float flowerMaxScale = 1.18;
说明：
  - 控制花朵整体缩放比例
  - flowerMinScale 是最小花
  - flowerMaxScale 是最大花

【根茎弹出摆动】
代码：float stemSwing = 10;
说明：
  - 控制花朵生长时根茎的弹出摆动幅度
  - 数值越大，生长时晃动越明显
  - 数值越小，生长更安静

【带叶子概率】
代码：float leafyFlowerChance = 0.18;
说明：
  - 控制花朵长出叶子的概率
  - 0.18 表示约 18%
  - 0 表示永远没有叶子
  - 1 表示每朵花都有叶子

----------------------------------------
花朵根茎曲线
----------------------------------------

【根茎末端弯曲范围】
代码：
  float stemBendMin = -42;
  float stemBendMax = 42;
说明：
  - 控制根茎顶端相对底部的左右偏移范围
  - stemBendMin 是最左偏移
  - stemBendMax 是最右偏移
  - 如果觉得根茎太偏，可以把范围改小，例如 -24 到 24

【控制点高度比例】
代码：
  float stemControlMin = 0.24;
  float stemControlMax = 0.72;
说明：
  - 控制曲线弯曲发生的位置
  - 数值越小，曲线更早弯
  - 数值越大，曲线更靠上弯

【控制点左右随机偏移】
代码：float stemControlJitter = 38;
说明：
  - 控制根茎中间控制点的左右随机范围
  - 数值越大，根茎越容易弯得明显
  - 数值越小，根茎更直

【新芽抽出深度】
代码：
  float sproutDepthMin = 8;
  float sproutDepthMax = 22;
说明：
  - 控制花朵从地下抽出来的初始深度
  - 数值越大，抽出的感觉越明显

----------------------------------------
空格吹风和背景花瓣
----------------------------------------

【背景花瓣数量上限】
代码：int maxWindPetals = 26;
说明：
  - 控制画面中最多同时存在多少片背景花瓣
  - 数值越大，花瓣越多，但可能更卡
  - 数值越小，画面更清爽

【背景花瓣生成速度】
代码：float windPetalRate = 1.0;
说明：
  - 空格触发后，背景花瓣持续生成的速度
  - 数值越大，风中花瓣越密
  - 数值越小，花瓣越稀疏

【背景花瓣移动速度】
代码：float windPetalSpeed = 0.6;
说明：
  - 控制背景花瓣从右上到左下飘动的速度
  - 数值越大，飘得越快
  - 数值越小，飘得越慢

【花朵受风摆动幅度】
代码：float flowerBlowSwing = 15;
说明：
  - 控制按空格后花朵向左摆动的整体幅度
  - 数值越大，花朵摆得越明显
  - 数值越小，花朵摆得更轻

【风力衰减速度】
代码：float windFade = 0.935;
说明：
  - 控制空格触发后的风持续多久
  - 数值越接近 1，风吹得越久
  - 数值越小，风更快消失

【背景花瓣持续时间】
代码：
  float windPetalLifeMin = 260;
  float windPetalLifeMax = 440;
说明：
  - 控制每片背景花瓣在画面中存在多久
  - 数值越大，花瓣停留越久
  - 数值越小，花瓣更快消失

【空格立即出现的花瓣数量】
代码：float windPetalBurstCount = 14;
说明：
  - 控制每次按空格时，立刻生成多少片背景花瓣
  - 数值越大，按下后花瓣越明显
  - 数值越小，花瓣不会太集中

【背景花瓣出生区域】
代码：
  float windPetalStartXMin = 0.54;
  float windPetalStartXOut = 260;
  float windPetalStartYMin = -230;
  float windPetalStartYMax = 0.48;
说明：
  - windPetalStartXMin 控制出生区域左边界
  - windPetalStartXOut 控制右侧画面外延伸距离
  - windPetalStartYMin 控制最高出生位置
  - windPetalStartYMax 控制最低出生位置
  - 想让花瓣更分散，可以增大 windPetalStartXOut，或让 windPetalStartYMin 更小

【背景花瓣出现时间错开】
代码：float windPetalDelayMax = 90;
说明：
  - 控制花瓣生成后显现时间的错开程度
  - 数值越大，花瓣越不会同一瞬间出现
  - 数值越小，花瓣出现更集中


========================================
6. 常见问题
========================================

问题1：背景不显示
  - 检查 background.jpg 是否在 AprilTextFall.pde 同一个文件夹
  - 检查文件名是否完全一致，包括大小写

问题2：字体和预期不一样
  - 当前使用 Songti SC，这是系统字体名称
  - 如果电脑里没有这个字体，Processing 可能会自动替换
  - 可以改用同文件夹里的 Fangzheng.ttf

问题3：鼠标碰到文字没有反应
  - 检查鼠标是否真的靠近文字笔画
  - 可以把 triggerRadius 调大，例如从 24 改到 32

问题4：花太多或画面太乱
  - 降低 triggerRadius，让文字不那么容易触发
  - 降低 flowerMaxScale，让花整体更小
  - 降低 leafyFlowerChance，减少带叶子的花

问题5：背景花瓣太多
  - 降低 maxWindPetals
  - 降低 windPetalRate
  - 降低 windPetalBurstCount

问题6：背景花瓣持续太短
  - 提高 windPetalLifeMin
  - 提高 windPetalLifeMax

问题7：花朵被风吹得太明显
  - 降低 flowerBlowSwing
  - 或降低 Flower 类中的 windFlex 随机范围

问题8：运行卡顿
  - 当前版本已经去掉发光图层和模糊滤镜
  - 如果仍然卡，可以降低 maxWindPetals
  - 也可以减少文字触发数量，避免同时生成过多花朵


========================================
结束
========================================

这个程序的核心是：
  鼠标触碰文字 -> 文字散成花瓣 -> 花瓣落下 -> 落点长出花朵 -> 空格吹动背景花瓣和花朵

如果要继续调整画面气质，建议优先从这几个参数开始：
  - fontSize
  - lineHeight
  - startY
  - petalBurstPower
  - flowerMaxHeight
  - flowerBlowSwing
  - windPetalSpeed
