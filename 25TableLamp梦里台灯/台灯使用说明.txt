========================================
1. 基本信息
========================================

程序名称：梦里台灯交互程序
开发环境：Processing 3.x 或 4.x
画布尺寸：600 x 800 像素
主要特点：
  - 蓝色渐变艺术台灯
  - 拉绳开关交互
  - 开灯后切换为黄色发光状态
  - 开灯后背景出现白色闪烁星星
  - 灯罩、灯杆、底座都可以单独调整颜色和位置


========================================
2. 安装与运行
========================================

步骤1：安装 Processing
  - 访问 https://processing.org/download
  - 下载并安装适合你电脑系统的版本

步骤2：打开项目文件夹
  - 找到项目文件夹：table_lamp
  - 打开 table_lamp.pde

步骤3：运行程序
  - 点击 Processing 左上角的运行按钮
  - 或按快捷键：
    Windows/Linux：Ctrl + R
    Mac：Cmd + R

注意：
  - 本程序不需要额外安装音效库
  - 本程序不需要 data 文件夹
  - 直接运行 .pde 文件即可


========================================
3. 交互方式
========================================

鼠标交互：
  - 鼠标按住右侧小吊坠
  - 向下拉动开关
  - 拉到最下方附近时，台灯会切换状态

灯光状态：
  - 默认状态：蓝色台灯
  - 开灯状态：黄色灯光、暖色台灯、背景出现星星
  - 再次拉动开关：切回默认状态


========================================
4. 画面结构说明
========================================

画面由这些部分组成：
  - 背景纸张
  - 开灯后的黄色光晕
  - 开灯后出现的白色小星星
  - 台灯底座
  - 灯杆
  - 正梯形灯罩主体
  - 灯罩下方椭圆，上下两部分组成
  - 顶部椭圆开口
  - 右侧拉绳开关

图层顺序：
  1. 背景纸张
  2. 黄色灯光
  3. 星星
  4. 灯杆和底座
  5. 灯罩
  6. 顶部椭圆
  7. 拉绳开关

5. 参数调整指南
========================================

提示：
  - 使用 Ctrl + F 或 Cmd + F 搜索参数名称
  - 修改数值后重新运行程序查看效果

----------------------------------------
画布和整体缩放
----------------------------------------

【画布尺寸】
位置：setup()
代码：size(600, 800);
说明：
  - 600 是画布宽度
  - 800 是画布高度

【原始设计稿尺寸】
代码：
  float designW = 840;
  float designH = 1080;
说明：
  - 下面大部分位置参数都按 840 x 1080 写
  - 程序会自动缩放到 600 x 800

----------------------------------------
台灯整体位置
----------------------------------------

【台灯左右位置】
代码：float shadeX = 420;
说明：
  - 数值越大，整盏灯越往右
  - 数值越小，整盏灯越往左

【灯罩上下位置】
代码：float shadeY = 235;
说明：
  - 数值越大，灯罩越往下
  - 数值越小，灯罩越往上

----------------------------------------
拉绳开关
----------------------------------------

【拉绳左右位置】
代码：float switchX = 550;
说明：
  - 数值越大，拉绳和吊坠越往右

【吊坠初始高度】
代码：float switchRestY = 595;
说明：
  - 数值越大，吊坠初始位置越低

【吊坠最大下拉位置】
代码：float switchPullLimit = 610;
说明：
  - 数值越大，可以拉得越低

【拉绳顶部连接点】
位置：drawPullSwitch()
代码：line(switchX, shadeY + 316, switchX, switchY - 14);
说明：
  - shadeY + 316 控制拉绳顶部连接点的上下位置
  - switchY - 14 控制拉绳下端连接到吊坠的位置

----------------------------------------
灯光效果
----------------------------------------

【灯光位置】
位置：drawLightAura()
代码：ellipse(shadeX, shadeY + 210, i * 3.0, i * 3.0);
说明：
  - shadeX 控制灯光中心左右位置
  - shadeY + 210 控制灯光中心上下位置
  - i * 3.0 控制灯光宽度和高度

【灯光扩散范围】
位置：drawLightAura()
代码：for (int i = 300; i > 0; i--)
说明：
  - 300 越大，光晕范围越大

【灯光透明度】
位置：drawLightAura()
代码：float alpha = map(i, 260, 0, 0, 20);
说明：
  - 20 越大，光晕越明显
  - 20 越小，光晕越柔和

----------------------------------------
星星效果
----------------------------------------

【星星数量】
代码：int starCount = 50;
说明：
  - 数值越大，星星越多

【星星大小】
位置：setupStars()
代码：starSize[i] = random(3, 9);
说明：
  - 3 是最小星星大小
  - 9 是最大星星大小

【星星闪烁频率】
位置：drawStars()
代码：float twinkle = 0.65 + 0.35 * sin(frameCount * 0.035 + starTwinkle[i]);
说明：
  - 0.035 越大，闪烁越快
  - 0.035 越小，闪烁越慢

【星星颜色】
位置：drawStars()
代码：fill(255, 255, 255, 235);
说明：
  - 前三个 255 是 RGB 颜色
  - 235 是透明度
示例：
  - 淡蓝色：fill(210, 240, 255, 235);
  - 暖黄色：fill(255, 245, 190, 235);

----------------------------------------
灯罩颜色
----------------------------------------

【顶部椭圆颜色】
代码：
  color blueTopCenter = #006bed;
  color blueTopOuter = #77d2fe;
说明：
  - blueTopCenter 是中心颜色
  - blueTopOuter 是外圈颜色

【灯罩主体颜色】
代码：
  color blueBodyTop = #7dd9ff;
  color blueBodyBottom = #dff4ff;
说明：
  - blueBodyTop 是梯形上方颜色
  - blueBodyBottom 是梯形下方颜色

【灯罩底部椭圆颜色】
代码：
  color blueShadeBottomEllipseTop = #c8eeff;
  color blueShadeBottomEllipseBottom = #dff4ff;
说明：
  - Top 控制椭圆上半部分
  - Bottom 控制椭圆下半部分

----------------------------------------
灯杆和底座颜色
----------------------------------------

【灯杆颜色】
代码：
  color bluePoleTop = #ccf0ff;
  color bluePoleBottom = #80d8ff;
说明：
  - bluePoleTop 是灯杆上方颜色
  - bluePoleBottom 是灯杆下方颜色

【底座颜色】
代码：
  color blueBaseOuter = #baebff;
  color blueBaseInner = #e0f1ff;
说明：
  - blueBaseOuter 是底座外圈颜色
  - blueBaseInner 是底座中心颜色

6. 常见问题
========================================

问题1：拉开关没有反应
  - 确认鼠标按在右侧小吊坠附近
  - 检查 switchPullLimit 是否太接近 switchRestY
  - 当前触发条件是拉到 switchPullLimit 附近

问题2：星星看不见
  - 星星只在开灯状态出现
  - 拉下开关后才会显示
  - 可以增大 fill(255, 255, 255, 235) 里的透明度数值

问题3：灯光太亮或太暗
  - 到 drawLightAura() 中调整透明度
  - 修改 map(...) 最后的 20

问题4：想让灯更靠上或靠下
  - 修改 shadeY
  - 或分别调整 drawShade()、drawStand()、drawTopOpening() 中的 y 坐标

问题5：想让星星不闪
  - 在 drawStars() 中把 twinkle 改成固定值：
    float twinkle = 1.0;
