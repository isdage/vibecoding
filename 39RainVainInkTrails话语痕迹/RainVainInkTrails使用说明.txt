========================================
1. 基本信息
========================================

程序名称：RainVainInkTrails 雨蚀心迹
开发环境：Processing 3.x 或 4.x
画布尺寸：600 x 800 像素

主要特点：
  - 使用 background.jpg 作为背景图
  - 中文和英文两行文字会像打字机一样同步出现
  - 中文和英文会同时开始、同时结束
  - 文字完全出现后，按空格键触发黑色墨痕流动
  - 墨痕只从英文这一行文字下方流出
  - 墨痕会在约 1.5 秒内慢慢出现
  - 按空格后文字会在约 2 秒内慢慢叠厚，不会突然变粗
  - 按 R 可以重置画面


========================================
2. 安装与运行
========================================

步骤1：安装 Processing
  - 访问 https://processing.org/download
  - 下载并安装适合你电脑系统的版本

步骤2：打开项目文件夹
  - 找到项目文件夹：RainVainInkTrails
  - 打开 RainVainInkTrails.pde

步骤3：确认资源文件
  - background.jpg 需要和 RainVainInkTrails.pde 放在同一个文件夹里
  - 当前程序不需要安装额外库
  - 当前程序不使用声音、麦克风或摄像头

步骤4：运行程序
  - 点击 Processing 左上角的运行按钮
  - 或按快捷键：
    Windows/Linux：Ctrl + R
    Mac：Cmd + R

注意：
  - 如果背景没有显示，优先检查 background.jpg 文件名是否完全一致
  - 如果中文字体显示异常，可以把 createFont("Songti SC", letterSize, true) 中的字体名换成电脑里已有的中文字体
  - 如果英文字体显示异常，可以把 createFont("Georgia", letterSize, true) 中的字体名换成电脑里已有的英文字体


========================================
3. 交互方式
========================================

程序开始：
  - 画面先显示背景图
  - 中文和英文两行文字同步以打字机效果出现
  - 两行文字会同时开始，也会同时结束

按空格键：
  - 当两行文字完全出现后，按空格键
  - 英文文字下方开始流出黑色半透明墨痕
  - 墨痕不是突然出现，而是慢慢显现
  - 按空格前如果文字还没有完全出现，墨痕不会触发

按 R 键：
  - 重置画面
  - 文字会重新从打字机效果开始
  - 墨痕和残影会清空


========================================
4. 画面结构说明
========================================

画面由这些部分组成：
  - 背景图片 background.jpg
  - 上方中文文字
  - 下方英文文字
  - 英文下方流出的黑色墨痕粒子

图层顺序：
  1. 背景图片
  2. 黑色墨痕粒子
  3. 中文文字
  4. 英文文字

说明：
  - 中文和英文都被拆成单个字符对象
  - 中文只负责显示，不生成墨痕
  - 英文字符既负责显示，也作为墨痕的起点
  - 墨痕使用 Perlin noise 控制流动方向
  - 背景会以很低透明度反复覆盖画面，让旧墨痕慢慢淡去

5. 参数调整指南
========================================

提示：
  - 使用 Ctrl + F 或 Cmd + F 搜索参数名称
  - 修改数值后重新运行程序查看效果
  - 建议每次只改一两个参数，方便判断变化

----------------------------------------
文字内容
----------------------------------------

【中文文字】
代码：
  String chinesePhrase = "那天，那句话，像雨一样腐蚀侵入了我的心";
说明：
  - 修改引号里的内容即可更换中文句子

【英文文字】
代码：
  String phrase = "That day, those words seeped into my heart like rain, slowly corroding it.";
说明：
  - 修改引号里的内容即可更换英文句子
  - 墨痕只会从英文这一行流出

----------------------------------------
文字排版
----------------------------------------

【字号】
代码：float letterSize = 13;
说明：
  - 控制中英文两行文字大小
  - 数值越大，文字越大
  - 数值越小，文字越小

【中文高度】
代码：chineseY = paddingTop - 32;
说明：
  - 控制中文行的位置
  - 减号后面的数值越大，中文越靠上

【英文高度】
代码：englishY = paddingTop;
说明：
  - 控制英文行的位置
  - 当前英文行作为墨痕起点

----------------------------------------
打字机效果
----------------------------------------

【打字速度】
代码：float typingSpeed = 0.42;
说明：
  - 控制文字出现速度
  - 数值越大，打字越快
  - 数值越小，打字越慢
  - 中英文会按各自长度比例同步出现，所以会同时结束

----------------------------------------
墨痕效果
----------------------------------------

【粒子寿命】
代码：float maxLife = 10;
说明：
  - 控制单个墨痕粒子的生命周期
  - 数值越大，粒子存活越久
  - 数值越小，粒子更快重生

【流场噪声尺度】
代码：float noiseScale = 200;
说明：
  - 控制墨痕流动的弯曲纹理
  - 数值越大，流动更舒展
  - 数值越小，流动变化更密集

【流动速度】
代码：float simulationSpeed = 0.2;
说明：
  - 控制墨痕粒子移动速度
  - 数值越大，墨痕流动越快
  - 数值越小，墨痕流动越慢

【墨痕淡入时间】
代码：float trailFadeFrames = 90;
说明：
  - 控制按空格后墨痕从无到有的时间
  - 90 大约是 1.5 秒
  - 数值越大，墨痕出现越慢

【文字叠厚速度】
代码：float textBuildFadeFrames = 120;
说明：
  - 控制按空格后文字逐渐变厚的速度
  - 120 大约是 2 秒
  - 数值越大，文字变厚越慢

【流场区域大小】
代码：float innerSquare = 512;
说明：
  - 控制墨痕活动区域大小
  - 当前是一个 512 x 512 的中心区域

----------------------------------------
背景图片
----------------------------------------

【背景文件】
代码：bg = loadImage("background.jpg");
说明：
  - 背景图片文件名必须是 background.jpg
  - 图片需要放在 RainVainInkTrails.pde 同一个文件夹里
  - 程序会自动把背景图缩放到 600 x 800

6. 常见问题
========================================

问题1：按空格没有反应
  - 需要等中英文两行文字完全出现后再按空格
  - 如果还在打字过程中，空格不会触发墨痕

问题2：背景没有显示
  - 检查 background.jpg 是否在 RainVainInkTrails 文件夹里
  - 检查文件名是否完全一致，包括大小写和后缀

问题3：中文显示成方块或乱码
  - 电脑可能没有 Songti SC 字体
  - 可以把 createFont("Songti SC", letterSize, true) 改成其他中文字体名称
  - 例如：PingFang SC、SimSun、Microsoft YaHei

问题4：英文太长或超出画面
  - 可以调小 letterSize
  - 也可以缩短 phrase 里的英文句子

问题5：墨痕太淡
  - 找到 updateInkTrails() 里的 fill(0, 255 * fadeRatio * 0.36 * appear);
  - 把 0.36 改大，例如 0.48

问题6：墨痕太浓
  - 找到 updateInkTrails() 里的 fill(0, 255 * fadeRatio * 0.36 * appear);
  - 把 0.36 改小，例如 0.22

问题7：想重新看打字效果
  - 按 R 键即可重置

结束
========================================

当前版本交互顺序：

  2. 等文字完全出现
  3. 按空格键
  4. 英文下方流出黑色墨痕
  5. 按 R 键重置
