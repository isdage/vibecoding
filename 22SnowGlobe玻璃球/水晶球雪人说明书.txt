====================================
     水晶球雪人 - Processing程序说明书
====================================

【程序简介】
这是一个交互式的水晶球雪人动画程序，使用Processing开发。
画面展示了一个装有雪人的水晶球，可以通过声音（吹气）与雪花互动。

【功能特点】
1. 美丽的渐变背景和水晶球效果
2. 可爱的雪人（带帽子、眼睛、鼻子、纽扣和树枝手臂）
3. 飘落的雪花（100片）
4. 闪烁的星光效果（50颗星星在整个画面闪动）
5. 声音交互：对着麦克风吹气可以让雪花飞舞起来

【系统要求】
- Processing 3.0 或更高版本
- 需要安装 Processing Sound 库
- 电脑需要麦克风

【安装步骤】
1. 下载并安装 Processing（https://processing.org/download）
2. 打开 Processing
3. 安装 Sound 库：
   - 菜单：Sketch → Import Library → Add Library
   - 搜索 "Sound"
   - 安装 "Sound" 库（by The Processing Foundation）
4. 将代码复制到 Processing 编辑器
5. 点击运行按钮（或按 Ctrl+R / Cmd+R）

【首次运行】
- 程序会请求麦克风权限，请允许
- 如果没有声音响应，检查系统麦克风权限设置

【使用方法】
1. 运行程序后，会看到水晶球和雪人
2. 雪花会自动缓慢飘落
3. 对着麦克风吹气或发出声音，雪花会加速飞舞
4. 星光会在整个画面持续闪烁

【调整参数】
如果需要调整灵敏度，可以修改代码中的以下参数：

1. 麦克风灵敏度（第13行）：
   float blowThreshold = 0.2;
   - 数值越小越敏感（范围：0.1 - 0.5）
   - 如果太容易触发，增大这个值
   - 如果吹气没反应，减小这个值

2. 雪花数量（第30行）：
   for (int i = 0; i < 100; i++)
   - 修改100为其他数字可改变雪花数量
   - 建议范围：50-150

3. 星光数量（第35行）：
   for (int i = 0; i < 50; i++)
   - 修改50为其他数字可改变星光数量
   - 建议范围：20-80

4. 雪花速度：
   - 第109-110行控制初始速度
   - 第117行的 blowStrength 控制吹气时的强度

【画面元素说明】
- 背景：径向渐变（中心白色到边缘浅蓝色）
- 水晶球：半透明的圆形，带有渐变效果
- 雪地：白色的半圆形，在水晶球底部
- 雪人：
  * 身体：两个白色圆球，带有左右渐变
  * 帽子：紫灰色三角形
  * 眼睛：两个灰色小圆点
  * 鼻子：橙色三角形
  * 纽扣：三个深灰色圆点
  * 手臂：棕色树枝状
- 底座：梯形，蓝色渐变
- 雪花：100片白色圆点，会飘落和飞舞
- 星光：50颗四角星，随机闪烁

【层次顺序】（从后到前）
1. 背景
2. 星光（在背景上）
3. 水晶球
4. 雪地
5. 雪人
6. 雪花（最前面）
7. 底座

【颜色配置】
- 背景渐变：中心 #FFFFFF → 边缘 #DDF6FF
- 水晶球渐变：中心 #FFFFFF → 外圈 #A0D9FF
- 雪人身体：左 #FFFFFF → 右 #E4F8FF
- 雪人头部：右 #E4F8FF → 左 #FFFFFF
- 帽子：#9A9CBA
- 底座渐变：上 #B4C6E3 → 下 #85A5DC

【技术特点】
- 使用径向渐变实现水晶球效果
- 使用线性渐变实现雪人和底座效果
- 平滑的速度过渡（使用 lerp 函数）
- 实时麦克风音量检测
- 粒子系统（雪花和星光）
- 碰撞检测（雪花与球壁）

【常见问题】
Q: 麦克风没反应？
A: 检查系统麦克风权限，调小 blowThreshold 值

Q: 雪花太少或太多？
A: 修改第30行的雪花数量

Q: 程序运行很卡？
A: 减少雪花或星光数量

Q: 想调整水晶球大小？
A: 修改第18行的 ballRadius 值（默认200）

Q: 如何保存画面？
A: 按键盘任意键时，可以在代码中添加保存功能

【代码结构】
主要类：
1. Sparkle 类：控制星光闪烁效果
2. Snowflake 类：控制雪花飘落和飞舞
3. 主程序：setup() 和 draw() 函数
4. 绘制函数：
   - drawRadialGradientBackground() 背景
   - drawCrystalBall() 水晶球
   - drawSnowGround() 雪地
   - drawBase() 底座
   - drawSnowman() 雪人
   - drawLinearGradientCircle() 渐变圆

【交互说明】
声音控制：
- 吹气或发出声音时，雪花会向上飞舞
- 音量越大，雪花飞得越快
- 停止声音后，雪花会缓慢落下
- 触发阈值可通过 blowThreshold 调整
