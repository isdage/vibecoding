========================================
1. 基本信息
========================================

程序名称：UnsentLetter 未寄出的信
开发环境：Processing 3.x 或 4.x
画布尺寸：600 x 800 像素

主要特点：
  - 使用 background.jpg 作为信纸背景
  - 使用 经典宋体简.ttf 作为诗句字体
  - 诗句初始为模糊状态
  - 鼠标靠近某一行文字时，该行会逐渐变清晰
  - 鼠标离开后，文字会慢慢退回模糊
  - 同一时间只有距离鼠标最近的一行会响应鼠标
  - 画面中会随机出现少量水滴涟漪
  - 水滴附近的文字会短暂变清晰一点
  - 右下角有单独的“我爱你。”文字，可单独调整位置和大小


========================================
2. 安装与运行
========================================

步骤1：安装 Processing
  - 访问 https://processing.org/download
  - 下载并安装适合你电脑系统的版本

步骤2：打开项目文件夹
  - 找到项目文件夹：UnsentLetter
  - 打开 UnsentLetter.pde

步骤3：确认资源文件
  - background.jpg 需要和 UnsentLetter.pde 放在同一个文件夹里
  - 经典宋体简.ttf 需要和 UnsentLetter.pde 放在同一个文件夹里
  - 当前程序不需要安装额外库
  - 当前程序不使用声音、麦克风或摄像头

步骤4：运行程序
  - 点击 Processing 左上角的运行按钮
  - 或按快捷键：
    Windows/Linux：Ctrl + R
    Mac：Cmd + R

注意：
  - 如果背景没有显示，优先检查 background.jpg 文件名是否完全一致
  - 如果字体没有显示，优先检查 经典宋体简.ttf 是否和 pde 文件在同一文件夹
  - 如果修改了资源文件名，需要同步修改代码里的 loadImage() 或 createFont()


========================================
3. 交互方式
========================================

鼠标靠近文字：
  - 程序运行后，诗句默认是模糊的
  - 将鼠标移动到某一行文字附近，该行文字会逐渐变清楚
  - 鼠标越靠近文字，文字越清楚
  - 鼠标离开后，文字会慢慢重新模糊
  - 为了避免多行同时被触发，程序会自动选择离鼠标最近的一行

水滴交互：
  - 画面中会随机出现少量圆形水滴涟漪
  - 水滴不是从上方落下的雨线，而是在纸面上像水渍一样出现
  - 水滴附近的文字会被短暂“擦亮”，稍微变清晰
  - 水滴涟漪会慢慢扩散并消失

右下角文字：
  - “我爱你。”是单独添加的一行文字
  - 它也会参与鼠标靠近变清晰的交互
  - 它的位置和大小可以单独调整


========================================
4. 画面结构说明
========================================

画面由这些部分组成：
  - 背景图片 background.jpg
  - 模糊/清晰变化的诗句文字
  - 右下角“我爱你。”文字
  - 随机出现的水滴涟漪
  - 水滴对文字清晰度的短暂影响

图层顺序：
  1. 背景图片
  2. 水滴涟漪
  3. 诗句文字
  4. 右下角“我爱你。”文字

说明：
  - 每一行文字都是一个独立对象
  - 每一行都有自己的清晰度 clarity
  - 鼠标距离文字越近，目标清晰度越高
  - 水滴会给附近文字增加 rainBoost
  - 文字模糊使用 PGraphics 小图层和 BLUR 滤镜实现
  - 水滴也使用 PGraphics 小图层绘制，避免整张画布反复模糊造成卡顿


========================================
5. 参数调整指南
========================================

提示：
  - 使用 Ctrl + F 或 Cmd + F 搜索参数名称
  - 修改数值后重新运行程序查看效果
  - 建议每次只改一两个参数，方便判断变化

----------------------------------------
画布和资源
----------------------------------------

【画布尺寸】
位置：setup()
代码：size(600, 800);
说明：
  - 600 是画布宽度
  - 800 是画布高度

【背景图片】
代码：backgroundImage = loadImage(sketchPath("background.jpg"));
说明：
  - 背景图片文件名必须是 background.jpg
  - 图片需要放在 UnsentLetter.pde 同一文件夹中
  - 程序会把背景图缩放到 600 x 800

【文字字体】
代码：
  String fontFileName = "经典宋体简.ttf";
  font = createFont(sketchPath(fontFileName), poemTextSize, true);
说明：
  - 字体文件名必须和代码中的 fontFileName 完全一致
  - 字体文件需要放在 UnsentLetter.pde 同一文件夹中
  - 如果换字体，只需要改 fontFileName 的文件名

----------------------------------------
文字排版
----------------------------------------

【诗句大小】
代码：float poemTextSize = 15;
说明：
  - 控制正文诗句字号
  - 数值越大，文字越大
  - 数值越小，文字越小

【诗句左右位置】
代码：float letterX = 115;
说明：
  - 控制正文诗句整体左侧位置
  - 数值越大，整体越靠右
  - 数值越小，整体越靠左

【诗句起始高度】
代码：float poemStartY = 235;
说明：
  - 控制正文第一段的起始高度
  - 数值越大，整首诗越靠下
  - 数值越小，整首诗越靠上

【段内行距】
代码：float lineGap = 25;
说明：
  - 控制同一段内每行文字之间的距离
  - 数值越大，段内行距越松
  - 数值越小，段内行距越紧

【段落间距】
代码：float paragraphGap = 50;
说明：
  - 控制段落和段落之间的距离
  - 数值越大，段落之间空隙越大
  - 数值越小，段落之间更紧凑

【正文分段】
位置：setup()
代码：
  y = addParagraph(new String[] {
    "后来雨一直下。",
    "我写了三遍你的名字，",
    "停了一会儿。"
  }, y);
说明：
  - 每一个 addParagraph() 是一个段落
  - 花括号里面的每一行文字会按 lineGap 排列
  - 每段结束后会自动增加 paragraphGap

【右下角“我爱你。”位置和大小】
代码：
  float loveTextX = 395;
  float loveTextY = 525;
  float loveTextSize = 15;
说明：
  - loveTextX 控制左右位置，数值越大越靠右
  - loveTextY 控制上下位置，数值越大越靠下
  - loveTextSize 控制字号大小

----------------------------------------
鼠标靠近文字
----------------------------------------

【文字变清晰速度】
代码：float clearSpeed = 0.08;
说明：
  - 控制鼠标靠近后文字变清晰的速度
  - 数值越大，清晰得越快
  - 数值越小，清晰得越慢

【文字重新模糊速度】
代码：float blurBackSpeed = 0.05;
说明：
  - 控制鼠标离开后文字重新模糊的速度
  - 数值越大，模糊得越快
  - 数值越小，模糊得越慢

【鼠标影响范围】
代码：float mouseAffectDistance = 85;
说明：
  - 鼠标距离文字多近时开始让文字变清楚
  - 数值越大，越容易触发文字
  - 数值越小，需要更靠近文字

【完全清晰距离】
代码：float mouseFullClearDistance = 30;
说明：
  - 鼠标距离文字多近时，文字接近最清楚
  - 数值越大，较远距离也容易变得很清楚
  - 数值越小，需要更贴近文字

----------------------------------------
水滴数量和出现范围
----------------------------------------

【水滴出现频率】
代码：float rainChance = 0.01;
说明：
  - 控制水滴出现的概率
  - 数值越大，水滴出现越频繁
  - 数值越小，水滴出现越少

【同时存在的水滴数量】
代码：int maxRainDrops = 3;
说明：
  - 控制画面上最多同时出现几滴水
  - 当前最多同时出现 3 滴
  - 想更少可以改成 2

【水滴随机出现范围】
位置：draw()
代码：
  rainDrops.add(new RainDrop(random(70, width - 70), random(140, 560)));
说明：
  - 第一个 random() 控制左右范围
  - 70 是左边界
  - width - 70 是右边界
  - 第二个 random() 控制上下范围
  - 140 是上边界
  - 560 是下边界

----------------------------------------
水滴影响文字
----------------------------------------

【水滴影响文字的强度】
代码：float rainClearAmount = 1.5;
说明：
  - 控制水滴让附近文字变清晰的程度
  - 数值越大，水滴影响越明显
  - 数值越小，水滴影响越弱

【水滴影响文字的范围】
代码：float rainAffectDistance = 80;
说明：
  - 控制水滴距离文字多近时会影响文字清晰度
  - 数值越大，影响范围越大
  - 数值越小，影响范围越小

----------------------------------------
水滴涟漪视觉
----------------------------------------

【水滴停留时间】
代码：float waterLife = 170;
说明：
  - 控制水滴从出现到消失的时间
  - 数值越大，水滴停留越久
  - 数值越小，水滴消失越快

【水波亮色】
代码：color rippleLightColor = color(248, 247, 240);
说明：
  - 控制水波亮边颜色
  - 当前是中性偏暖的浅灰白，避免泛蓝

【水波暗色】
代码：color rippleDarkColor = color(118, 116, 108);
说明：
  - 控制水波暗边颜色
  - 当前是中性偏暖灰

【水波透明度】
代码：
  float rippleLightAlpha = 54;
  float rippleDarkAlpha = 42;
说明：
  - rippleLightAlpha 控制亮色水痕明显程度
  - rippleDarkAlpha 控制暗色水痕明显程度
  - 数值越大，水滴越明显

【水滴大小】
位置：RainDrop()
代码：
  stainSize = random(12, 24);
  maxRipple = random(70, 105);
说明：
  - stainSize 控制中心水渍大小
  - maxRipple 控制涟漪最大扩散范围
  - random() 里的两个数字分别是最小值和最大值

【水滴柔化程度】
位置：RainDrop.display()
代码：waterLayer.filter(BLUR, 1.7);
说明：
  - 控制水滴边缘的柔和程度
  - 数值越大，水滴越模糊柔和
  - 数值越小，水滴边缘越清楚


========================================
6. 常见问题
========================================

问题1：背景图没有显示
  - 确认 background.jpg 和 UnsentLetter.pde 在同一个文件夹
  - 确认文件名完全是 background.jpg
  - 如果改了文件名，需要同步修改 loadImage(sketchPath("background.jpg"))

问题2：字体没有显示或变成默认字体
  - 确认 经典宋体简.ttf 和 UnsentLetter.pde 在同一个文件夹
  - 确认代码里的 fontFileName 和字体文件名完全一致
  - 如果字体文件名包含空格或特殊字符，也必须在代码中完全一致

问题3：鼠标靠近文字没有变清晰
  - 检查 mouseAffectDistance 是否太小
  - 可以把 mouseAffectDistance 从 85 改成 100 测试
  - 检查 clearSpeed 是否过小，过小会让变化非常慢

问题4：靠近文字时多行一起变清晰
  - 当前程序会自动选择最近的一行，一般不会同时触发多行
  - 如果感觉影响范围仍然太大，可以减小 mouseAffectDistance

问题5：水滴太多或太少
  - 修改 rainChance 控制出现频率
  - 修改 maxRainDrops 控制同时存在的水滴数量

问题6：水滴影响文字太明显
  - 减小 rainClearAmount
  - 或减小 rainAffectDistance

问题7：水滴影响文字不明显
  - 增大 rainClearAmount
  - 或增大 rainAffectDistance

问题8：水滴颜色不合适
  - 修改 rippleLightColor 和 rippleDarkColor
  - 如果不想泛蓝，保持 RGB 三个数字接近
  - 例如 color(118, 116, 108) 会比 color(62, 142, 196) 更偏灰

问题9：水滴消失太快
  - 增大 waterLife
  - 例如从 170 改成 220

问题10：运行有卡顿
  - 减小 maxRainDrops
  - 减小 maxRipple 的最大值
  - 减小 waterLayer.filter(BLUR, 1.7) 的模糊数值
  - 减小水滴存在时间 waterLife
