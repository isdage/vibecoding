========================================
1. 基本信息
========================================

程序名称：ThousandWordsLove 千言万语流星文字
开发环境：Processing 3.x 或 4.x
画布尺寸：600 x 800 像素

主要特点：
  - 使用 data/background.jpg 作为背景图片
  - 使用系统自带黑体类字体，优先尝试 Heiti SC
  - 画面上方不断落下类似流星的文字光点
  - 大部分文字隐藏在流星光点里，只有碰到输入框时才短暂显示
  - “我 / 喜 / 欢 / 你”四个字会以黄色流星出现，其他字为较弱的灰色流星
  - 鼠标控制一个白色透明输入框，去接住目标文字
  - 输入框只会按顺序收集“我、喜、欢、你”
  - 非目标字碰到输入框后会反弹，并短暂显示后消失
  - 集齐“我喜欢你”后，输入框位置固定，右侧出现发送按钮
  - 鼠标悬停到发送按钮上，按钮会轻微放大和上浮
  - 点击发送按钮后，输入框、文字和按钮会以不同频率闪动并逐渐消失
  - 按空格键可以重新开始


========================================
2. 安装与运行
========================================

步骤1：安装 Processing
  - 访问 https://processing.org/download
  - 下载并安装适合你电脑系统的版本

步骤2：打开项目文件夹
  - 找到项目文件夹：ThousandWordsLove
  - 打开 ThousandWordsLove.pde

步骤3：确认资源文件
  - background.jpg 需要放在 ThousandWordsLove/data 文件夹里
  - 当前路径应为：ThousandWordsLove/data/background.jpg
  - 当前代码使用系统字体，不需要额外字体文件
  - 当前程序不需要安装额外库
  - 当前程序不使用声音、麦克风或摄像头

步骤4：运行程序
  - 点击 Processing 左上角的运行按钮
  - 或按快捷键：
    Windows/Linux：Ctrl + R
    Mac：Cmd + R

注意：
  - 如果背景没有显示，优先检查 data 文件夹里是否有 background.jpg
  - 如果字体和预期不一样，说明系统没有找到优先字体，程序会自动尝试后备字体
  - 如果画面明显卡顿，可以先降低 maxWords，或调大 wordSpawnInterval


========================================
3. 交互方式
========================================

移动鼠标：
  - 程序开始后，鼠标控制画面中的白色透明输入框
  - 未集齐前鼠标指针隐藏，只保留输入框跟随鼠标移动
  - 输入框可以从流星出现开始就接住文字

接住文字：
  - 输入框只会按顺序收集“我、喜、欢、你”
  - 当前需要的字碰到输入框时，会进入输入框中
  - 例如还没有收集任何字时，只能接住“我”
  - 接住“我”后，下一个需要接住的是“喜”
  - 非当前需要的字碰到输入框时，会反弹落下，并短暂显示它是什么字

集齐文字：
  - 当输入框收集到完整的“我喜欢你”后，输入框会停在当前位置
  - 鼠标指针重新出现
  - 输入框右侧出现一个浅色圆形发送按钮

发送按钮：
  - 鼠标移动到发送按钮上，按钮会轻微放大并上浮
  - 点击发送按钮后，“我喜欢你”、输入框和按钮会闪动并逐渐消失
  - 闪动消失没有额外烟花、花朵或爆炸效果

重新开始：
  - 按空格键可以重置画面
  - 所有流星、已收集文字、输入框锁定状态和发送状态都会恢复初始状态


========================================
4. 画面结构说明
========================================

画面由这些部分组成：
  - 背景图片 background.jpg
  - 灰色普通流星文字
  - 黄色目标流星文字
  - 鼠标控制的白色透明输入框
  - 输入框中的“我喜欢你”
  - 集齐后出现的发送按钮

图层顺序：
  1. 背景图片
  2. blur 柔光图层
  3. 清晰流星拖尾和亮点
  4. 碰撞后短暂显示的文字
  5. 输入框、输入文字、发送按钮

说明：
  - 每个下落元素都是一个 FallingWord 对象
  - 每个 FallingWord 内部保存自己的轨迹点 trail，用来绘制流星拖尾
  - 黄色流星代表“我 / 喜 / 欢 / 你”
  - 灰色流星代表其他随机中文单字
  - blur 发光统一画在 glowLayer 上，再整体模糊一次
  - 输入框位置由鼠标控制，集齐后通过 lockedBoxX 和 lockedBoxY 固定
  - 发送后的消失效果由 messageSent 和 sentFadeAlpha 控制


========================================
5. 参数调整指南
========================================

提示：
  - 使用 Ctrl + F 或 Cmd + F 搜索参数名称
  - 修改数值后重新运行程序查看效果
  - 建议每次只改一两个参数，方便判断变化
  - 如果运行卡顿，优先减少数量和 blur，而不是继续加强发光

----------------------------------------
画布和资源
----------------------------------------

【画布尺寸】
位置：setup()
代码：size(600, 800);
说明：
  - 600 是画布宽度
  - 800 是画布高度

【背景图片】
代码：String backgroundFile = "background.jpg";
说明：
  - 图片文件名必须是 background.jpg
  - 图片需要放在 ThousandWordsLove/data 文件夹中
  - 程序会按画布比例自动裁切铺满背景

【背景变暗】
代码：int backgroundDarkAlpha = 0;
说明：
  - 控制背景上是否覆盖黑色透明蒙版
  - 0 表示不额外压暗背景
  - 数值越大，照片越暗

【系统字体】
代码：
  String[] preferredFontNames = {
    "Heiti SC",
    "STHeiti",
    "STHeitiSC-Light",
    "STHeitiSC-Medium",
    "PingFang SC",
    "Microsoft YaHei",
    "SimHei",
    "Noto Sans CJK SC",
    "Source Han Sans SC"
  };
说明：
  - 程序会按顺序寻找系统里存在的字体
  - macOS 一般优先使用 Heiti SC
  - 如果想换字体，可以把想要的字体名称放在列表最前面
  - 运行时控制台会打印：Using system font: 字体名

----------------------------------------
流星丛数量 / 密度 / 速度 / 大小
----------------------------------------

【碰撞后显示的文字大小】
代码：
  float fallingWordMinSize = 10;
  float fallingWordMaxSize = 18;
说明：
  - 控制流星碰到输入框后，显示出来的文字大小范围
  - fallingWordMinSize 是最小字号
  - fallingWordMaxSize 是最大字号

【流星生成密度】
代码：int wordSpawnInterval = 3;
说明：
  - 控制多久生成一颗新流星
  - 数值越小，流星越密
  - 数值越大，流星越稀疏
  - 如果卡顿，可以把 3 改成 5、7 或 9

【同屏流星数量】
代码：int maxWords = 150;
说明：
  - 控制画面中最多保留多少颗流星
  - 数值越大，画面越满，但更容易卡
  - 数值越小，画面更清爽，也更流畅

【流星下落速度】
代码：
  float fallSpeedMin = 3.0;
  float fallSpeedMax = 8.2;
说明：
  - 控制流星随机下落速度范围
  - fallSpeedMin 是最慢速度
  - fallSpeedMax 是最快速度
  - 如果想更慢、更轻，可以整体调小

【目标字整体比例】
代码：float wantedDropChance = 0.30;
说明：
  - 控制“我 / 喜 / 欢 / 你”整体在随机流星里的出现比例
  - 0.30 表示约 30%
  - 数值越大，黄色目标流星越多

【“你”的出现概率】
代码：float niChanceInWanted = 0.10;
说明：
  - 控制随机目标字里“你”的比例
  - 数值越小，最后一个“你”越难等到
  - 数值越大，越容易集齐“我喜欢你”

----------------------------------------
流星闪烁 / 发光 / 拖尾
----------------------------------------

【闪烁速度】
代码：
  float twinkleSpeedMin = 0.035;
  float twinkleSpeedMax = 0.075;
说明：
  - 控制每颗流星明暗变化的速度范围
  - 数值越大，闪烁越快
  - 数值越小，闪烁越慢

【黄色柔光范围】
代码：float targetGlowSize = 24;
说明：
  - 控制“我 / 喜 / 欢 / 你”黄色流星的柔光范围
  - 数值越大，黄色光更明显
  - 数值越小，黄色光更收敛

【灰色柔光范围】
代码：float noiseGlowSize = 10;
说明：
  - 控制普通灰色流星的柔光范围
  - 数值越大，灰色光越明显
  - 数值越小，灰色光越弱

【黄色亮度】
代码：float targetGlowStrength = 1.35;
说明：
  - 控制黄色目标流星的亮度强度
  - 数值越大，黄色流星越突出

【灰色亮度】
代码：float noiseGlowStrength = 0.86;
说明：
  - 控制普通灰色流星的亮度强度
  - 数值越小，灰色流星越暗
  - 想突出黄色流星，可以适当降低这个值

【流星尾巴长度】
代码：
  float meteorTrailMin = 78;
  float meteorTrailMax = 185;
说明：
  - 控制流星拖尾的随机长度范围
  - meteorTrailMin 是最短尾巴
  - meteorTrailMax 是最长尾巴
  - 数值越大，流星感越强，但画面也更容易糊和卡

【流星亮点大小】
代码：
  float meteorCoreMin = 2.6;
  float meteorCoreMax = 8.4;
说明：
  - 控制流星头部亮点大小
  - 数值越大，头部越亮越圆
  - 如果不想头部太像圆点，可以适当调小

【拖尾轨迹点数量】
代码：int maxTrailCount = 30;
说明：
  - 控制每颗流星保留多少个历史位置来画拖尾
  - 数值越大，尾巴越长、更连续，但更容易卡
  - 数值越小，尾巴更短，性能更好

【叠加发光模式】
代码：boolean useAdditiveGlow = true;
说明：
  - true 会用 ADD 模式把光叠加到背景上
  - false 会使用普通混合模式，画面更淡、更克制

【柔光图层分辨率】
代码：float glowScale = 0.5;
说明：
  - 控制 blur 发光图层的分辨率
  - 0.5 表示用 300 x 400 的小图层绘制，再放大到 600 x 800
  - 数值越大，发光更细，但更卡
  - 数值越小，性能更好，但光可能更粗

【整体 blur 强度】
代码：float glowBlurAmount = 4;
说明：
  - 控制 blur 柔光的模糊程度
  - 数值越大，光越散，也越耗性能
  - 如果卡顿，可以降低到 2 或 3

【柔光图层整体透明度】
代码：float glowLayerAlpha = 185;
说明：
  - 控制整个发光图层叠到画面上的透明度
  - 数值越大，所有流星光更亮
  - 数值越小，整体更淡

【碰撞后文字消失速度】
代码：float hitRevealFadeSpeed = 7;
说明：
  - 非目标字碰到输入框后，会短暂显示再消失
  - 数值越大，文字消失越快
  - 数值越小，文字停留更久

========================================
6. 常见问题
========================================

问题1：背景不显示
  - 检查 background.jpg 是否放在 ThousandWordsLove/data 文件夹中
  - 检查文件名是否完全一致，包括大小写
  - Processing 的 data 文件夹需要和 ThousandWordsLove.pde 在同一个项目文件夹下

问题2：字体不是黑体
  - 程序会从 preferredFontNames 列表中按顺序寻找系统字体
  - 如果系统里没有 Heiti SC，可能会自动使用 PingFang SC 或 Serif
  - 运行时看控制台的 Using system font，可以知道实际使用了哪个字体
  - 想强制使用某个字体，可以把它的系统名称放到 preferredFontNames 的第一项

问题3：画面卡顿
  - 把 maxWords 调小，例如从 150 改成 80 或 100
  - 把 wordSpawnInterval 调大，例如从 3 改成 5 或 7
  - 把 glowBlurAmount 调小，例如从 4 改成 2
  - 把 maxTrailCount 调小，例如从 30 改成 18
  - 把 glowScale 保持在 0.5 或更低

问题4：黄色目标字太少
  - 提高 wantedDropChance
  - 提高 niChanceInWanted 会让“你”更容易出现
  - 但如果太高，会很快集齐“我喜欢你”

问题5：太快集齐“我喜欢你”
  - 降低 wantedDropChance
  - 降低 niChanceInWanted
  - 提高 fallSpeedMin 和 fallSpeedMax 会让接字更难
  - 减小 boxW 或 boxH 也会让接字更难

问题6：流星太密或太乱
  - 调大 wordSpawnInterval
  - 调小 maxWords
  - 降低 meteorTrailMax
  - 降低 glowLayerAlpha

问题7：黄色流星不够明显
  - 提高 targetGlowStrength
  - 提高 targetGlowSize
  - 降低 noiseGlowStrength
  - 降低 noiseGlowSize

问题8：普通灰色流星太抢眼
  - 降低 noiseGlowStrength
  - 降低 noiseGlowSize
  - 降低 glowLayerAlpha

问题9：输入框太透明或太明显
  - 调整 boxFillAlpha
  - 数值越小越透明
  - 数值越大越明显

问题10：点击发送键没有反应
  - 需要先完整集齐“我喜欢你”
  - 集齐后输入框右侧才会出现发送按钮
  - 鼠标需要点击圆形按钮区域

问题11：想重新开始
  - 直接按空格键
  - 空格会清空当前状态并重新生成流星


========================================
结束
========================================

这个程序的核心是：
  千言万语像流星落下 -> 输入框只接住真正想说的字 -> 组成“我喜欢你” -> 点击发送 -> 文字和按钮闪动消失

如果要继续调整画面气质，建议优先从这几个参数开始：
  - wordSpawnInterval
  - maxWords
  - wantedDropChance
  - niChanceInWanted
  - targetGlowStrength
  - noiseGlowStrength
  - meteorTrailMax
  - boxLetterSpacing
  - sentFadeSpeed
