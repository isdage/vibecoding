项目简介
--------
《泡泡纸》是一款以“戳泡泡”为灵感的互动可视化作品。用户可在屏幕上悬停与按压泡泡，
体验“轻凹—加压—爆裂—波纹扩散—淡出”的完整视觉过程。作品强调微妙的视觉反馈与
顺滑的动画过渡，不包含任何声音功能。

核心交互与视觉机制
------------------
- 悬停轻凹：鼠标悬停在泡泡上会产生轻微压陷（HOVER_DENT）。
- 按压加力：按住鼠标左键对当前泡泡持续“加压”，压力达到阈值（POP_THRESHOLD）后爆裂。
- 爆裂表现：爆裂后泡泡中心塌陷、出现透明残膜并生成向外扩散的同心波纹；波纹逐渐变淡直至消失。
- 修复功能：按住 SHIFT 再点击已爆的泡泡，可立即“修复”为充气状态。
- 版式自适应：根据窗口尺寸自适应网格与半径，保持布局比例与视觉节奏一致。
- 背景渐变：采用中心至边缘的径向暖色渐变，提升层次与对比度。
- 无声音：本作品不包含任何声音播放或麦克风交互。

操作说明（Controls）
-------------------
- 悬停（Hover）：将鼠标移至泡泡上方，泡泡会轻微下陷。
- 按住左键（Press & Hold）：对悬停的泡泡持续加压，超过阈值即爆裂并触发波纹动画。
- SHIFT + 点击（Repair）：修复已爆泡泡为充气状态。
- R（Reset）：重置整个网格，所有泡泡回到初始充气状态。

安装与运行
----------
方式一：源码运行（推荐）
1. 安装 Processing 4.x（Java 模式）：https://processing.org/download
2. 打开项目中的 sketch_13__.pde
3. 点击左上角 ▶️ 运行即可体验交互

方式二：导出应用程序
1. 在 Processing 中打开 sketch_13__.pde
2. 选择 File > Export Application...
3. 勾选对应平台（macOS / Windows）并导出 .app / .exe 直接运行

系统需求
--------
- 操作系统：macOS / Windows / Linux
- 软件环境：Processing 4.x（Java 模式）
- 图形渲染：P2D（默认），可在 settings() 中切换 fullScreen(P2D)

文件说明
--------
- sketch_13__.pde：主程序代码（包含网格布局、交互与渲染逻辑）
  - 网格参数：COLS0 / ROWS0 / DIAM0 / GAP0
  - 交互参数：PRESSURE_RATE / POP_THRESHOLD / HOVER_DENT
  - 视觉函数：drawRadialGradient()；缓动函数：easeOutQuad()
- /data（可选）：若后续添加图片或其他视觉资源，可放置于此

常见问题与小贴士
--------------
- 如果窗口尺寸变化，作品会自动根据当前窗口进行响应式布局与缩放。
- 如需全屏展示，可将 settings() 中的 size(...) 改为 fullScreen(P2D)（注意显示器分辨率）。
- 若要加入截图或声音等扩展功能，可在 keyPressed() 中添加自定义按键逻辑，或引入 Sound 库。
